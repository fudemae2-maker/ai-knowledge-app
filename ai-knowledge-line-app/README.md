# 📱 AIナレッジ Pocket - LINE簡単共有アプリ

スマホでAIと対話した知見・アイデア・ToDo・要点を自動で構造化し、ワンタップでLINEに共有できる**完全無料のWeb/PWAアプリケーション**です。

---

## ✨ 主な特徴

1. **初期・月額費用 0円（完全無料）**:
   - **AI対話・要約**: Google Gemini API の無料枠（Free Tier）を利用（1日1,500回まで無料）。APIキーなしでも即試せるデモAIモード内蔵。
   - **LINE連携**: 公式のLINE共有URLスキーム（`line://` / Web Share）を使用。LINE公式アカウントの課金や審査は一切不要。
   - **データ保存**: スマホ本体（ブラウザ内LocalStorage）に安全に保存。外部データベース費用0円＆プライバシー安全。
   - **サーバー代**: GitHub Pages / Vercel / Cloudflare Pages などの無料ホスティングで永久0円公開可能。

2. **スマホ特化UI ＆ PWA対応**:
   - 親指で操作しやすいボトムナビゲーション。
   - iPhone（Safari）やAndroid（Chrome）の「ホーム画面に追加」で、本物のアプリ同様に全画面で起動。
   - ダークモード / ライトモードの自動・手動切り替え対応。

3. **スマートナレッジ抽出**:
   - 会話の中から「要約サマリー」「主要な知見」「ToDoチェックリスト」「タグ」をAIが自動抽出。
   - カテゴリ分類（仕事、アイデア、学習、生活、ToDo）とお気に入り登録。

4. **ワンタップLINE共有**:
   - **要約版**（短くすっきり）、**詳細版**（ToDo＋知見）、**ToDo版**（チェックリスト）を用途に合わせてワンタップで生成。
   - ボタンを押すだけでスマホのLINEアプリが開き、友だちやグループ、自分専用の「Keepメモ」へ即座に送信。

## 🚀 使い方・起動方法

### ① ローカルで今すぐ試す場合
フォルダ内の `index.html` をダブルクリックしてブラウザで開くか、Python等のローカルサーバーで起動できます。

```bash
# Pythonで簡易サーバーを起動する場合（例）
python -m http.server 8000
```
ブラウザで `http://localhost:8000` を開きます。

---

### ② スマホから使えるように無料公開する手順（3分で完了）

#### おすすめ: GitHub Pages または Vercel を使う方法（無料）
1. **GitHub Pages の場合**:
   - このフォルダ内のファイル一式をGitHubリポジトリにアップロード（push）。
   - リポジトリの **Settings ➔ Pages** から、Branchを `main`（root）にして **Save**。
   - 数分で発行される `https://<ユーザー名>.github.io/<リポジトリ名>` にスマホからアクセス。

2. **Vercel の場合**:
   - [vercel.com](https://vercel.com) に無料登録。
   - リポジトリを連携するかフォルダをドラッグ＆ドロップしてデプロイ。即座にHTTPS対応URLが発行されます。

---

### ③ スマホのホーム画面に追加してアプリ化（PWA）

* **iPhone (Safari) の場合**:
  1. 公開URLをSafariで開く
  2. 画面下部中央の **「共有ボタン（四角から上矢印）」** をタップ
  3. メニューから **「ホーム画面に追加」** を選択
  4. ホーム画面にアイコンが追加され、全画面アプリとして起動可能になります。

* **Android (Chrome) の場合**:
  1. 公開URLをChromeで開く
  2. 右上の **「3点リーダー（メニュー）」** をタップ
  3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップ

---

### ④ 無料のGemini APIキーを取得して設定する方法（約1分）

1. [Google AI Studio](https://aistudio.google.com/app/apikey) にアクセスし、Googleアカウントでログイン。
2. **「Create API Key」**（APIキーを作成）をクリック。
3. 発行された `AIzaSy...` から始まるキーをコピー。
4. 本アプリの **「⚙️ 設定」** 画面を開き、APIキー欄に貼り付けて **「AI設定を保存」** を押すだけです。

## 🔒 プライバシーとセキュリティ
* 入力したAPIキーや会話データ、ナレッジはすべて**お使いの端末（ブラウザ）内にのみ暗号化保存**されます。
* 外部の独自サーバー等に会話履歴が送信されることは一切ありません。
